# Rittenworx Handyman — SEO Audit & Competitive Analysis
**Site:** rittenworxhandyman.net &nbsp;|&nbsp; **Date:** 2026-07-06 &nbsp;|&nbsp; **Scope:** Full site (source + live crawl)

## Summary

The site's technical SEO foundation is solid (canonical tags, structured data, sitemap, redirect hygiene). The audit found and **fixed one live bug** (16 broken internal links), and surfaced a **duplicate-content risk** in the programmatic location pages as the top structural issue. Keyword coverage is strong for core services but has clear, competitor-validated gaps (deck, fence, pressure washing, popcorn ceiling removal).

### Broken links (fixed in this PR)
`src/pages/services/[slug].astro` generates 64 pages (8 services × 8 cities). Two of those cities — **Owens Cross Roads** and **Redstone Arsenal** — have no matching page under `/locations/`, but the breadcrumb on every one of their 16 generated pages linked to `/locations/owens-cross-roads` and `/locations/redstone-arsenal`, both confirmed live 404s (verified via direct crawl). Fixed by pointing those breadcrumbs to the real `/locations/huntsville` hub (both places are in the Huntsville metro area). No other broken internal links were found in the sampled crawl (homepage, service, location, and blog templates).

### Page speed
- LCP handling is good: the homepage hero image is preloaded with `fetchpriority="high"` and explicit `width`/`height`.
- `public/images/owner.webp` is **646 KB** — 10–20× larger than every other image on the site — and is loaded on the homepage with no `width`/`height` attributes and no lazy-loading. It's below the fold but still competes for bandwidth with the LCP image and risks layout shift. Recommend re-compressing to <60 KB and adding explicit dimensions.
- `public/hero-handyman.png` (71 KB) and `public/hero-maintenance-roy.png` (59 KB) are unreferenced leftovers now that `.webp` versions are in use — safe to delete, no live impact but repo clutter.
- Full Lighthouse/PageSpeed API scoring could not be run in this environment (Google's PSI API rate-limited the request); recommend running `PageSpeed Insights` or a Lighthouse CI job directly against the production URL for hard scores.

## 2. On-Page SEO

- **Title tags:** all ~27 static page titles reviewed — **no duplicates**. Good.
- **Meta descriptions:** generally strong (benefit-led, include phone number/CTA). **9 pages exceed the ~155–160 character guideline** and will be truncated in search results:

| Page | Length | 
|---|---|
| `services/general-handyman.astro` | **184 chars** (worst) |
| `services/exterior-painting.astro` | 168 |
| `services/flooring.astro` | 165 |
| `locations/decatur.astro` | 164 |
| `locations/decatur/burningtree.astro` | 163 |
| `locations/athens.astro` | 163 |
| `locations/madison/harvest.astro` | 163 |
| `services/drywall.astro` / `services/finish-carpentry.astro` | 162 |
| `locations/huntsville.astro` | 162 |

  Blog post descriptions (23 posts) are consistently well-sized and unique — no action needed there.

- **Duplicate/thin-content risk (top finding):** The 64 programmatic `/services/{service}-{city}` pages share ~90% identical body copy — only the service name and city name change in an otherwise fixed template (same 4-step process, same 4 FAQs, same "why choose us" bullets). Meanwhile the standalone `/services/drywall` (etc.) pages *also* mention all 4 core cities, and the standalone `/locations/madison` (etc.) pages *also* list all services. For a query like "drywall repair Madison AL," **up to three separate pages** on the site could compete for the same intent. This is a classic pattern search engines increasingly discount as low-value/doorway content, and it risks internal cannibalization (the wrong page ranking, or none ranking well).
- **Orphan pages:** the Owens Cross Roads and Redstone Arsenal combo pages (16 total) are reachable only via the sitemap — no internal page links to them. Redstone Arsenal is a federal military/NASA installation, not a residential area, so targeting "handyman services at Redstone Arsenal" is questionable relevance to begin with; worth reconsidering as a target city.

## 3. Keyword Analysis

**Well covered:** `handyman [city] AL` for all 4 core markets, 7 services × 4 cities in on-page copy, dedicated combo landing pages for 8 cities/neighborhoods, and a smart "how much does X cost" blog format (interior painting, LVP flooring, gutter installation, finish carpentry, cabinet painting) that matches high-intent transactional search behavior.

**Gaps identified** (cross-checked against Rittenworx's actual service list and legacy redirects, which show several of these were previously live pages now collapsed into a generic `/services` redirect):

| Keyword / topic | Intent | Why it matters |
|---|---|---|
| Deck/patio construction & repair | Transactional | No dedicated page; `deck-building-repair.html` now redirects to generic `/services` |
| Fence installation/repair | Transactional | Same — `fence-installation-repair.html` now redirects to generic `/services` |
| Pressure/power washing | Transactional | Same — `pressure-washing.html` now redirects to generic `/services`; ties naturally into existing seasonal-maintenance blog content |
| Popcorn ceiling removal | Transactional | No page at all; natural drywall/paint crossover with strong local search signal |
| Window/screen & storm-door repair | Transactional | `door-window-installation.html` redirects to generic `/services` |
| Gutter guard installation | Transactional | Adjacent upsell to the existing gutter-cleaning/installation pages |
| "Handyman near me [city]" / "same day handyman [city]" | Transactional | Current titles use "Handyman [City] AL" — close, but doesn't mirror the literal "near me"/"same day" phrasing competitors title their pages with |
| City-specific cost guides for Huntsville/Decatur/Athens | Informational → transactional | Existing cost-guide posts skew Madison-specific; the other 3 core cities are under-served for "how much does X cost" searches |

Note: TV mounting, furniture assembly, and ceiling fan installation **are** already covered via `/services/general-handyman` — just not broken out into city-specific landing pages the way core services are.

## 4. Competitive Analysis

Researched via live web search against Rittenworx's internally tracked competitor list plus additional local players found on Yelp/Thumbtack.

- **Mr. Handyman of Huntsville** (national franchise) — the biggest content threat. Runs per-service-per-city pages (e.g. *"Deck Repair & Replacement in Madison, AL"*), publishes downloadable seasonal maintenance checklists, and has a much broader service catalog: deck/patio, fence, pressure washing, popcorn ceiling removal, window/screen repair, siding, gutter guards.
- **Hunkler Handyman** (Hartselle) — built dedicated **"[City] Handyman Near Me"** landing pages for the exact same 4 core cities Rittenworx targets (Madison, Huntsville, Decatur, Athens) — direct "near me" keyword competition.
- **Sir Fix A Lot** (Owens Cross Roads/Hampton Cove) — hyper-local, ZIP-level targeting, strong on door/frame repair and custom built-ins/closet-garage organization — direct carpentry overlap.
- **Chamblee Home Services** (Madison) — currently weak on content (blog still shows unpublished placeholder posts) — an opportunity, not a threat, right now.
- **Five Star Painting of Huntsville** and **Green Dot Painting (North Alabama)** — both run dedicated popcorn-ceiling-removal service pages, confirming that gap as a live, capturable keyword.
- **You Heard It Handyman** (Madison) — active blog, offers deck installs and remodeling/electrical/plumbing (outside Rittenworx's scope by design).

## 5. Top Recommendations

1. **Reduce duplicate/thin content in the 64 programmatic pages.** The 16 broken breadcrumb links are already fixed in this PR. Next step: make the highest-traffic service×city combos genuinely unique (local landmarks, pricing nuances, real project photos) and consider `noindex`-ing or merging the lowest-value combos — starting with Redstone Arsenal, which isn't a residential market.
2. **Trim the 9 over-length meta descriptions** to ≤155–160 characters, starting with `services/general-handyman.astro` (184 chars) so Google stops truncating them in search snippets.
3. **Build out the service gaps competitors already own:** deck repair, fence installation, pressure washing, and popcorn ceiling removal. Each ties naturally into existing carpentry/paint/drywall work and directly targets keywords Mr. Handyman, Sir Fix A Lot, and Five Star Painting are already capturing in this exact market.
4. **Extend the cost-guide blog format to Huntsville, Decatur, and Athens.** The format is clearly a good fit for local intent (per internal keyword tracking, "drywall repair madison al" and "kitchen cabinet painting athens" are already top-5 rankings) — replicate it for the two other core cities where coverage is thin.
5. **Close out the already-identified GSC housekeeping tasks** in `Offline Tasks for Rittenworx SEO.md` (request re-indexing of high-impression/zero-click pages, resubmit the sitemap, confirm `www` as the canonical domain) — these were documented previously but there's no evidence in the repo history that they've been executed.
